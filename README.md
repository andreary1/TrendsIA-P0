# P0-PRIMEIRO-FLUXO-LLM - ComunicadoAI

Interpretador inteligente de comunicados acadêmicos
desenvolvido em Python com integração à API do Google Gemini.

## Problema

Estudantes universitários precisam identificar manualmente
tarefas, prazos e orientações importantes em comunicados
acadêmicos escritos em linguagem natural.

## Objetivo

Desenvolver um programa que receba comunicados acadêmicos,
utilize um LLM para interpretar seu conteúdo e apresente
as informações relevantes de maneira organizada.

## Tecnologias

- Python
- Google Gemini API

## Estado do desenvolvimento

Projeto em fase inicial de configuração.
